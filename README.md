# My-personal-chrome.css-theme-for-firefox-oneliner
## Features
- One-line layout (tabs and navbar on same row)
- Back/forward buttons hidden when disabled, visible when active
- Minimal URL bar (no border/background at rest)
- Hidden: window controls, extensions button, URL bar icons
- Tab close button fades in on hover
- Window dims when out of focus

## Installation
1. Enable `toolkit.legacyUserProfileCustomizations.stylesheets` in `about:config`
2. Copy `userChrome.css` to your Firefox profile's `chrome/` folder
3. Restart Firefox
